# Утилита mtp
## Описание
Утилита для преобразования markdown файлов в pdf файлы на локальной машине
## Установка
Установить через go install
```bash
```
Если на системе нет Golang, то запустите таргет util-build. Этот таргет соберет утилиту в Docker контейнере на локальную машину
```bash
make util-build
```
## Запуск
В терминале нужно написать название утилиты. Если вы используете директорию, в которой лежат изображения для markdown файлов, вызывайте флаг -d и указывайте директорию
```bash
mtp -d ./test_directory
```
Если у вам просто один текстовый файл без графического содержания, то просто вызовите флаг -f для файла
```bash
mtp -f file.md
```
## Переменные окружения
|Переменная|Описание|
|----------|--------|
|FONT|Шрифт для компиляции в pdf формат|
|PATH|Путь для сохранения выходных файлов из утилиты|
|GOOGLE_DISK|Google диск для сохранения файлов (Необязательная переменная, если вы не хотите получать файлы на диск)|
|SAVE_PATH|Полный путь для, где должны сохраняться файлы|
